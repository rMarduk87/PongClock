What if time passed... playing Pong?
PongClock transforms a simple clock into something hypnotic, minimalist, and surprising.
A timeless classic that plays itself, ticking off the hours while the paddles battle it out autonomously.
🕒 A clock, but different from everything else
Time has never been so interesting to watch:
the game continues nonstop, and each point marks the passing of the minutes.
🎮 Automatic gameplay
No input required:
the AI ​​controls both paddles, and you enjoy the show.
Perfect for keeping on a desk, a second screen, or as a visual companion.
🎨 Unique Visual Modes
Customize your style with different modes:
Classic → essential and retro
Neon → bright and modern
Matrix → moving code
Breakout → a creative twist on gameplay
🍂 Automatic Dynamic Modes

Winter

Autumn
